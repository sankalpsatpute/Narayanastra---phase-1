
# Narayanastra — Phase 1

## 2D Autonomous Target Tracking & Interception Simulation

**Phase:** 1 of 2  
**Platform:** MATLAB  
**Status:**  Completed

---

## Overview

**Narayanastra — Phase 1** is a MATLAB-based 2D simulation that demonstrates an autonomous vehicle tracking a moving target using feedback control.

The project focuses on autonomous navigation, target tracking, vehicle dynamics, heading control, and real-time visualization.

> **Note:** This is an educational simulation focused on autonomous navigation and control-system concepts.

---

## Objectives

- Build a 2D simulation environment
- Generate a moving target
- Model an autonomous vehicle
- Calculate relative position and distance
- Implement feedback-based tracking
- Control vehicle heading
- Apply turn-rate limitations
- Visualize vehicle and target trajectories
- Analyze distance and heading errors
- Detect when the vehicle reaches the predefined simulation threshold
